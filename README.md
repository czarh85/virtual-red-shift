# Virtual Red Shift -- project page

This repository holds **web pages** and nothing else: the public page for an unofficial
Virtual Boy port of VVVVVV, and the notes of its private beta under `beta/`.

It contains no ROM, no game assets and no source code. The port itself is not public.

If you hold rights in anything shown on the page and want it changed or taken down, it
will be done, without discussion. The quickest route is a reply in the Planet Virtual Boy
thread where the beta is announced: https://www.virtual-boy.com/forums/t/beta-release-vvvvvv-red-shift/
